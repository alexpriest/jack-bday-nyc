# Jackhattan

Jack's birthday week — June 5–11, 2026. NYC + Westchester.

Collaborative planning site: drag-to-rearrange agenda, hour-by-hour calendar view, comparison tables for restaurants / bars / spas, live multi-user state via Firebase.

Live: https://alexpriest.github.io/jack-bday-nyc

## Stack

- Single-file `index.html` (no build step)
- Firebase Realtime Database (reuses `stoweaways-2026` project under `jack-bday-2026/*` namespace)
- SortableJS for drag-and-drop
- GitHub Pages for hosting

## Local dev

```
open index.html
```

That's it. Edit, refresh, commit, push.
